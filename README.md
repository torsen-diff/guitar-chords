# Guitar chord maker
(i know this sounds so corny, but I haven't thought of a better name for this project.)


# How does it work?
The way this code works is that you put in the input field notes, and it shows where on the fretboards those notes are. I have used european notation for this project, but it is really simple to change it to your own notation, just modify the arrays. There might be some notes that don't work, for example H## (B double sharp for americans) but I don't feel like I would ever use them.

Also ignore spaghetti code.
